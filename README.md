# Yining Lin — Personal Portfolio

An English-language, single-page portfolio featuring art, music, sport, economics, and community activities.

## Publishing

Enable GitHub Pages from the `main` branch, root folder. The site uses relative paths and works under `/Profile/`.

## Updating media

Replace the corresponding media file or update its filename in `site.json`. Keep `editingEnabled` set to `false` in the published copy. Saved uploads are managed in the separate local editor; GitHub Pages serves the visitor site only.

The guitar video is an optimized 720p copy; the original is preserved locally.
